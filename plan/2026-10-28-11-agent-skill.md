# Plan: a meetings skill for Claude, Codex and agy

## Approved decisions (copied from the spec)

- **Skill** `skills/meetingai/SKILL.md`, frontmatter `name: meetingai` and a
  description triggering on meeting notes, last meeting, action items, "what
  did we agree", transcript, standup, series. Body: use only
  `nixarchy-meetingai ctl <command> '<json>'` (`.data` holds the result,
  read with `jq`), mapping:
  recent meetings → `session.list` (kind `meeting`, newest first);
  latest notes → first meeting, then `notes.get {"meeting": id}`;
  search → `meetings.search {"query", "limit"}`; action items →
  `items.list {"meeting": id}`; series and last time → `series.list`,
  `last_time.get {"series": id}`; transcript → `transcript.get
  {"meeting": id, "limit": 200}` paged with `after_line`; the meeting now →
  `state.get`, `now.get`, `transcript.get {}`.
  Rules: read-only (never `record.*`, `session.delete`, `settings.set`,
  `items.update/delete`); daemon not running → say so and suggest
  `systemctl --user start nixarchy-meetingai`; quote notes as written;
  one line that what it reads goes to the agent's provider.
- **Daemon** (`src/daemon/session.rs`, `src/daemon/protocol.rs`), read-only:
  `session.list` meeting entries gain `started_at` (additive);
  `meetings.search {query, limit?}` calls `db::meetings::search` (titles,
  transcript lines, notes via `notes_fts`), returns `[{id, title,
  started_at}]`, limit default 10 clamped 1–50, hides local-only interview
  meetings (`candidates::local_only_ids`, as `session.list` does), empty
  query → "query is empty". No edits under `src/db/`.
- **Install:** `nix/package.nix` installs the skill to
  `share/nixarchy-meetingai/skills/meetingai/SKILL.md`; HM option
  `programs.nixarchy-meetingai.skills.enable` (default `true`) links that
  directory with `home.file` to `.claude/skills/meetingai`,
  `.agents/skills/meetingai` (Codex) and
  `.gemini/antigravity/skills/meetingai` (agy). README: "Ask your agents"
  section; options block regenerated.

## Repo traps

- `src/db/` belongs to rewrite #3 (step 4 not merged): call
  `meetings::search`, do not change it.
- `git add -N` new files before `nix flake check`.
- Commits by the lead with `SKIP_BUMP=1`; merge commits only.
- `home.file` targets that already exist make activation fail; none exist on
  p620 today (checked in step 3).
