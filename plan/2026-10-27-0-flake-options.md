# Plan: a complete flake: every install and configuration option in Nix

## Approved decisions (copied from the spec)

- **Outputs:** `packages.<sys>.{default, nixarchy-meetingai, plugin,
  whisper-model-small-en, whisper-model-small, whisper-model-large-v3-turbo}`;
  `overlays.default` adds `nixarchy-meetingai`, `nixarchy-meetingai-plugin`,
  `whisper-models.<name>`; `homeManagerModules.{default,nixarchy-meetingai}`;
  `checks.<sys>` with module evaluations and the package build.
- **Options** under `programs.nixarchy-meetingai`:
  - service: `enable`, `package`, `autostart` (true), `logLevel`
    (`info`, enum error/warn/info/debug/trace → `RUST_LOG`),
    `extraEnvironment` (attrs of str);
  - `whisper.{enable (true), model (large-v3-turbo), package
    (whisper-cpp-vulkan), host ("127.0.0.1"), port (8178), threads (null),
    extraArgs ([])}`; the daemon gets the address so it calls the same
    server;
  - `ollamaCloud.keyFile` (→ `LoadCredential=ollama:<path>`; the daemon
    reads `$CREDENTIALS_DIRECTORY/ollama` before `OLLAMA_API_KEY` and the
    vault), `ollamaCloud.environmentFile`, `ollama.url`
    ("http://127.0.0.1:11434");
  - `settings.{meetingMode, chatProvider, chatModel, liveProvider,
    liveModel, responsePace, responseLength, responseLanguage, autoResponse,
    smartFollowUps, autoRecordOnCall, speechProvider, speechModel,
    speechLanguage, textScale, reduceMotion, mcpAllowRecord, extra,
    enforce}`, all null by default; enum values come from a generated JSON
    checked against the Rust types;
  - `plugin.enable` (true; through `programs.nixarchy.plugins` when that
    option exists, else the current `xdg.configFile`), `keybindings`,
    `callDetection.enable` (true; adds the meeting-mode plugin unless an
    entry with that id exists).
- **Settings file:** `$XDG_CONFIG_HOME/nixarchy-meetingai/settings.json`
  `{"enforce": bool, "values": {...}}`; validated like `settings.set`;
  defaults applied once per (key, value hash) recorded in a
  `settings_seeded` table; with `enforce`, re-applied every start,
  `settings.set` refuses those keys ("Set in Nix"), replies carry
  `locked: [keys]`, the UI shows them disabled. `api_key` is rejected by an
  assertion.
- **Checks:** minimal and full module evaluation; assertions (whisper off
  with whisper-local speech, `api_key` in extra, both cloud key options);
  the full example's `settings.json` equals a fixture; a Rust test loads
  that fixture.
- **Docs:** README "Nix options" generated by `nix build .#docs`
  (`nixosOptionsDoc`) and committed; a check that it matches.

## Repo traps

- cargo only via `devenv shell -- <cmd>`; rustfmt only touched files.
- Shell tests run headless (`shell/tests/headless.sh`); never
  `MEETINGAI_ON_DESKTOP`.
- `nix flake check` sees only git-tracked files: `git add -N` new files
  before checking.
- Coders cannot commit; the lead commits each step.
- The meeting-mode flake input is
  `github:olafkfreund/nixarchy-meeting-mode`; its plugin package is
  `packages.<sys>.default` (as in the owner's `omarchy-meeting-mode.nix`).

## Steps

1. **Outputs.** `flake.nix`: the packages (plugin from `shell/` minus
   `shell/tests/`, the three whisper models from `nix/whisper-model.nix`),
   the overlay, the module aliases, a `nixarchy-meeting-mode` input
   (follows nixpkgs).
   → verify by `nix flake show` and `nix build .#plugin
   .#whisper-model-large-v3-turbo`.
2. **Service and whisper options** in `nix/hm-module.nix` (replace the
   fixed port "shortcut"); the daemon reads the whisper address from an
   env var (`NIXARCHY_MEETINGAI_WHISPER_URL`) set by the module.
   → verify by a module check with non-default values and a unit test for
   the env var.
3. **Providers.** `ollamaCloud.keyFile` (`LoadCredential`), `ollama.url`
   (env var to the daemon); daemon: credential first, then env, then vault;
   `ollama.url` must be loopback to count as local.
   → verify by unit tests (credential read, precedence, non-loopback url
   not local) and a module check.
4. **Settings.** Module writes `settings.json`; daemon loader in
   `src/core/models/settings.rs` (or a new `src/daemon/nix_settings.rs`)
   called at start (`src/daemon/mod.rs:36`); `settings_seeded` table
   (guarded); enforce: refuse in `settings_set` (`session.rs:3236`), `locked`
   in `settings` replies; UI disables locked controls with "Set in Nix";
   generated enums JSON + its test.
   → verify by `cargo test` (defaults once, changed Nix value re-applied
   once, enforce refuses and locks, invalid keys skipped) and a headless
   shell check for a locked control.
5. **Plugin and call detection.** `plugin.enable` through
   `programs.nixarchy.plugins` when available; `callDetection.enable`
   adding meeting-mode only when absent.
   → verify by two module checks: with a stub `programs.nixarchy.plugins`
   option (plugin registered there, meeting-mode added once even when
   already present) and without it (xdg path used).
6. **Checks and docs.** Assertions; the fixture check; `.#docs` and the
   README "Nix options" section; README install snippet updated.
   → verify by `nix flake check` and the docs-match check.
7. **Review:** Opus, then Codex (read-only); fix confirmed findings.

## Tests

`devenv shell -- cargo test --workspace --no-fail-fast`, clippy
`-D warnings`, `nix flake check`, the headless shell suite.

## Rollback

Each step is its own commit; every new option defaults to today's
behaviour, so reverting any step leaves existing installs working.

## Implementation split

One `coder` does steps 1–6 in order; the lead commits each step and runs
step 7.

## Deviations log (recorded with the implementation commit)

None yet.
- **Steps 1–6 (one commit; coders cannot commit):** `settings.textScale`
  is 80–160 (what the app clamps to), not 80–200. `logLevel` sets
  `RUST_LOG=nixarchy_meetingai=<level>` so dependencies stay quiet. The
  module is `self: inputs: { … }` to reach the meeting-mode input. The enum
  JSON (`nix/settings-enums.json`) is hand-written and a Rust test checks it
  against the types; the fixture test lives in `src/daemon/nix_settings.rs`.
  Ollama key order is credential file, then `OLLAMA_API_KEY`, then the vault
  (was vault first). `callDetection` sets the meeting-mode plugin with
  `mkDefault`, so a user's own entry wins. The headless check asserts that
  no `settings.set` is sent for locked keys (not each control's `enabled`).
  `providers.status` probes the configured Ollama address; IPv6 hosts are
  untested. The flake has no `nix fmt` formatter.
- **Lead fix:** `callDetection` keyed the meeting-mode plugin as
  `meeting-mode`, but owners declare it by its manifest id
  `nixarchy.meeting-mode` (e.g. `omarchy-meeting-mode.nix`), so both would
  install. It now uses `nixarchy.meeting-mode`; the check matches.
- **Review fixes:** `ollamaCloud.keyFile` is no longer `LoadCredential=` (a
  missing source stops the user unit with 243/CREDENTIALS). The module sets
  `NIXARCHY_MEETINGAI_OLLAMA_KEY_FILE=<path>`; the daemon reads it (trimmed),
  a missing or unreadable file means no key (warn once, never the content),
  then `OLLAMA_API_KEY`, then the vault. The daemon unit has
  `X-Restart-Triggers` (settings file, environment) and `Wants=` the whisper
  unit. `ollama.url` is asserted https or http on localhost/127.0.0.1/[::1]
  (exactly what the app's `endpoint_allowed` accepts, narrower than 127.0.0.0/8).
  The Nix whisper/ollama address wins over a stored base URL. `prompts.set`,
  `prompts.reset`, the mode and provider pickers honour `locked`. Provider
  settings are validated. A removed-then-re-added identical default is not
  re-applied (documented on `settings.enforce`).
- **Review fixes (Opus + Codex, step 7):** restart triggers on settings
  changes; the daemon `Wants=` whisper; `checks` build the package and the
  plugin; `ollama.url` asserted https or exactly localhost/127.0.0.1/[::1]
  (what `endpoint_allowed` accepts); IPv6 whisper hosts bracketed and
  wildcard binds mapped to loopback for the daemon; `%`/`$` escaped in
  whisper args; prompt Save/Reset refuse locked keys; locked mode and
  provider pickers disabled, `setProvider` returns early; provider ids
  validated; the Nix address beats a stored URL for whisper-local and
  ollama; the seeded-hash behaviour is documented in `settings.enforce`.
